NCEA LEVEL 3 91906-91907 

Personalised skincare checker
The personalised skincare checker is a digital solution designed to help users identify suitable skincare products based on their individual skin type and skin concerns. 

The program provides personalised skincare recommendations by collecting information from the user such as age, skin type, skin concerns, budget, and ingredient preference to compare the information against the product database to display suitable recommendations. This makes it easier for users to find products that are suitable for their individual needs.
